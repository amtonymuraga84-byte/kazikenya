Senior dbt Developer (Analytics Engineer)

Proxify AB · Remote · Posted 2026-11-19

Tech

About the role

Proxify AB, headquartered in Sweden, is hiring a remote Senior dbt Developer to own clients' dbt architecture and turn raw enterprise data into tested, documented models in cloud data warehouses. The role calls for 3+ years of production dbt experience, advanced SQL, dimensional modeling, Git-based CI/CD, and Python, with Snowflake, BigQuery or Databricks experience. Duties include optimizing slow models, setting up data quality tests, maintaining documentation and lineage, and running code reviews.
